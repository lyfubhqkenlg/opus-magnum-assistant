## Overview

Opus Magnum Puzzle Solver Assistant is a hint and reference tool for the puzzle game Opus Magnum, providing progressive hints for each puzzle that reveal just enough information to nudge thinking without spoiling the solution. It also tracks which puzzles have been completed and logs personal cost, cycle, and area scores for competition.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Opus Magnum Puzzle Solver Assistant** delivers the features you need in a clean, intuitive package.
